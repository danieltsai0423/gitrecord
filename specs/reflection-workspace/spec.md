# 回顧與節奏工作台

2026-10-04，Daniel 要求將建議的四項功能加進 GitRecord，依本專案用途調整創新，不照搬其他工具的介面或實作。

- 一個工作台整合期間摘要、帳號對照、節奏與每週目標，沿用全域帳號／repo／日期篩選。提供近 7／30 日入口與側欄導覽。
- 工作台位於每日報告之後、頁尾之前，側欄入口排在「每日報告」下方；總覽先呈現統計、代碼變更趨勢、repositories 與年度活動熱圖。文件總覽截圖完整包含趨勢圖與「每一日的積累」，回顧分頁另有獨立截圖。
- 摘要由本機統計產生，呈現活躍日、主要 repo、與等長前期的變化及月分布，不呼叫 AI 或新增 GitHub 權限。
- 帳號對照使用相同日期與相同尺度，呈現各帳號活動及共同活躍日；缺資料不當成零，也不產生生產力排名。
- 最長連續活動以選取日期內的日曆日計算，涵蓋不足／partial／保存的同步失敗時不宣稱確定紀錄。零行數 commit 仍是活動。
- 每週目標由使用者設定（0 表示未設定），以帳號範圍計算、不受 repo 篩選影響。週一到週日、截至選取結束日，跨帳號同日只算一次；未涵蓋日與未納入日明示。目標依穩定帳號 ID 或合計範圍保存在瀏覽器，儲存受限時仍可在本次使用。
- 期間回顧卡涵蓋當期摘要、月分布與主要 repos。原生 Canvas 輸出 PNG，也可複製 Markdown；有預覽，預設隱藏帳號與私人 repo 名稱，資料涵蓋與各帳號同步時間隨輸出保留，不送往第三方。
- 空活動、單帳號、長名稱、中英文、深淺主題、手機、鍵盤與列印均可使用。目標或對照操作不切換同步身分、不呼叫同步。
