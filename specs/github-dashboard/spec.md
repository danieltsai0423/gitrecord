# GitHub 每日代碼增修 Dashboard

**功能目錄**：`specs/github-dashboard`
**日期**：2026-10-02
**狀態**：已確認（使用者於 2026-10-02 確認）

此文件保留原始交付範圍。後續 GitHub App、多帳號、回顧工作台與開源版本的現行行為，以根目錄 README 與其他功能規格為準。

## 1. 概述

讓目前 GitHub 帳號的使用者查看每日代碼新增、刪除與淨增行數，透過趨勢圖、活動熱圖與 repository 排行理解工作量，並匯出可核對的統計報告。

## 2. 使用者情境

- 開啟 Dashboard，看到自己的真實 GitHub 資料、涵蓋期間、最後同步時間與當期統計。
- 切換日期範圍或 repository，所有統計與圖表同步變更。
- 更新資料，查看同步進度；失敗時能看到原因並保留上次成功報告。
- 匯出目前篩選結果，取得每日統計 CSV 與可列印報告。

## 3. 功能需求

| 編號 | 需求 | 驗收方式 |
|---|---|---|
| FR-001 | 自動使用目前登入的 GitHub 帳號，包含其擁有且有權限讀取的公開及私人 repositories | 帳號為目前登入者，repository 清單與帳號擁有清單一致；fork 明示排除 |
| FR-002 | 統計預設分支中屬於該帳號的非 merge commits；以 Asia/Taipei 的 commit 提交時間歸日 | 人工核對一個 commit 的帳號、日期、增刪行數；merge 不重複計入 |
| FR-003 | 每日提供新增、刪除、淨增、變更行數及 commit 數；無活動日期補零 | 淨增等於新增減刪除；變更等於新增加刪除；日期連續 |
| FR-004 | 預設顯示近 30 日，可切換 7、30、90、365 日及自訂日期，並篩選單一 repository | 每次篩選後摘要、趨勢、排行、每日明細一致；日期不可超過資料涵蓋範圍 |
| FR-005 | 提供當期摘要、增刪趨勢、全年活動熱圖、repository 排行與每日明細 | 每個視覺化使用真實同步資料，具明確數值、圖例與空資料狀態 |
| FR-006 | 提供手動同步、進度與最後成功同步時間，錯誤或不完整資料清楚標示 | 同步期間有進度；單 repo 失敗明示部分完成，不偽裝完整報告 |
| FR-007 | 匯出目前篩選的每日 CSV 與可列印統計報告 | CSV 合計符合畫面；列印樣式包含帳號、期間、規則與摘要 |
| FR-008 | 建立新的 GitHub repository 保存完整原始碼、規格、安裝及統計規則說明 | 提交可從新 repo 取得，依 README 安裝與啟動成功 |
