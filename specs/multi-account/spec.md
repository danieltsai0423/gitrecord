# 多帳號資料整合

日期：2026-10-03（Asia/Taipei）；2026-10-04 更新 GitHub App OAuth 需求。Daniel 在確認建議後要求實作，後續明確要求連 GitHub CLI 都不必安裝，並建立公開的 GitHub App。

每個 GitHub 帳號分別登入及同步，統計保存在本機；Dashboard 預設整合所有已保存帳號。直接使用 GitHub OAuth device flow 與 REST／GraphQL，憑證使用作業系統憑證管理保存。

## 行為與驗收

- 每次同步只更新 GitRecord 選中的授權帳號，其他帳號保留；再次同步同一帳號取代舊報告，不重複累加。帳號更名依 GitHub user ID 辨認，沒有 ID 的舊快取依 username 接續。
- 舊 version 1 單帳號快取自動載入為 version 2 集合，下次保存寫入新版；暫存檔加 rename 整份保存，寫入失敗不替換記憶體中的報告。
- 預設所有帳號合計；可篩選帳號及 repo，切換帳號篩選會重設 repo。不同 owner 的同名 repo 依完整名稱區分，排行顯示 owner。
- 摘要、趨勢、熱圖、每日明細同步依篩選變化；活躍日按日期去重，不是帳號活躍日數相加。
- 全域 GitHub 個人頁入口只保留右上角 icon；單一統計帳號時連至該帳號，所有帳號合計時連至目前授權帳號，無授權時以單一快取帳號作備援。Tooltip 與無障礙名稱顯示跳轉目標，點擊才開新分頁。
- 登入切換標示「同步帳號」，報告篩選標示「統計帳號」，手動同步標示「同步目前帳號」，避免把篩選誤認為登入切換。
- 帳號卡片顯示各自的同步時間、涵蓋日期及 partial／失敗狀態。合計視窗最多 365 日，依最新報告結束日期決定；未涵蓋日期明示部分資料，不能當成零活動。
- 帳號區塊可由右上角向上／向下按鈕收合，收合保留帳號數與目前授權帳號，隱藏帳號操作、設定及卡片；瀏覽器記住手動選擇，內容保留在頁面內以維持選單／表單值。新增登入、切換帳號、未連接、未完成安裝、設定與授權錯誤自動展開；按鈕支援鍵盤與 aria-expanded／aria-controls，中英文及手機皆可使用。收合本身不觸發同步。
- 日期涵蓋提示列出缺少資料的帳號與涵蓋日期，每個帳號提供「GitHub 存取設定」與「重新檢查」。對目前帳號重新核對授權／安裝，即使已就緒仍會同步；對其他已連接帳號切換後核對並同步。未連接帳號提供登入入口。非目前帳號的安裝連結使用 App 安裝入口並明示選擇對應 GitHub 帳號，避免跳至目前帳號的安裝設定；未安裝不得誤同步。同步／帳號操作期間停用檢查，失敗保留統計與可重試入口，統計篩選維持獨立。中英文、深淺色與手機均可使用。
- 全域同步失敗保留帳號先前報告；已確認且曾同步過的帳號保存失敗時間／原因，下次成功清除。首次失敗或無法辨認帳號的錯誤由同步訊息顯示。
- 每頁 commit 查詢核對 viewer ID；同步途中帳號變更中止整次同步，避免混入另一帳號權限下的資料。
- CSV／列印包含篩選帳號、各帳號同步時間及涵蓋範圍；部分資料或保存的失敗狀態明示 partial。涵蓋不足或同步不完整時不計算前期比較。
- 新增／首次登入均使用頁面按鈕直接啟動 GitHub OAuth device flow，顯示一次性 user code 與 GitHub 授權入口，不需要安裝 GitHub CLI。GitHub 頁面完成登入、2FA 與授權；成功後自動同步。
- 發布者建立一次 public GitHub App 並啟用 Device Flow，設定 Contents／Metadata 唯讀；公開 App ID、Client ID 與 slug 隨 repo 發布。一般使用者不必建立 App 或填寫設定。預設使用 Daniel 提供的 GitRecord by Daniel；缺少整組設定時顯示表單並停用登入。保存設定前核對 GitHub 公開 App 資料與唯讀權限。不需要 client secret 或私鑰，不請求 OAuth `repo` scope。
- OAuth 完成後核對個人帳號安裝。未安裝、空範圍、暫停或非唯讀權限時不得同步；提供前往 GitHub 安裝／選擇 repos 的按鈕，確認存取就緒後才自動同步。按安裝入口後每 5 秒檢查，最多等候 10 分鐘，可停止等待或手動重新檢查。
- 每次同步重新查詢本人 App 安裝，完整分頁取得所選 repository node ID，再依白名單分批讀取統計；未選取的公開 repos 也不納入。不使用 org 或其他使用者的安裝。範圍在查詢期間變更或清單分頁重複時停止，保留報告。管理範圍後按同步重新查詢。
- 已授權帳號可按「切換並同步」。此操作更新 GitRecord 的帳號選擇；統計篩選保持獨立。同步與登入／切換互斥，狀態核對期間也阻止帳號變更；可取消登入、重新授權、更新登入清單及移除本機登入。移除登入不刪除報告。
- 授權碼只保存在程序記憶體，成功／取消／失敗時清除。Access／refresh token 保存在 OS keychain，若不可用則僅保存在程序記憶體並顯示提示；不以明文保存。瀏覽器只取得帳號 metadata 與 user code，所有登入 API 沿用本機 Host 與來源保護。
- Token 到期時自動更新，同一帳號並行請求只更新一次；取得或更新 token 後核對 GitHub 身份。不同 Client ID 的憑證隔離；原有 CLI 或 OAuth App 登入需要在新 GitHub App 重新授權，報告快取沿用。

## 維持的統計範圍

各帳號 App 安裝範圍內、本人擁有的非 fork repositories、預設分支、該帳號作者的非 merge commits、Asia/Taipei committed date。組織名下 repos、未合併分支與未關聯帳號作者沿用排除規則。Commit 依各 repository 的統計合計；此功能不把不同 repo 的複製歷史視為同一 repo。

## 驗證

`npm.cmd test` 涵蓋快取轉換、合計／去重、同名 repo、單帳號更新、更名、日期涵蓋、保存失敗、同步失敗及途中切換帳號。

`npm.cmd run build` 驗證型別與 production build；`npm.cmd run test:e2e` 在桌面及手機驗證篩選、合計、CSV、列印、帳號狀態、操作指引與版面。測試不依賴真實 GitHub 憑證。

OAuth 模組測試與 API 測試涵蓋直接 HTTP 授權、pending／slow_down、到期更新、身份混用拒絕、取消、切換白名單、metadata 投影、來源保護與同步互鎖。GitHub App 測試核對公開資訊、唯讀權限、個人／org 安裝隔離、repo 白名單分頁與只查詢選取 repos。瀏覽器測試涵蓋 App 設定、零登入、授權／安裝／切換後自動同步、未安裝時禁止同步、session 提示、移除登入、帳號區塊收合與資料涵蓋修復；Windows OS 憑證管理使用隔離測試名稱驗證保存、重載及移除。2026-10-04 的 40 項核心／API 測試、production build 與 46 項桌面／手機 E2E 均通過；已設定公開 App，兩個真人帳號已完成授權、安裝及所選 repos 同步，報告涵蓋至 2026-10-04，皆無 partial 或同步錯誤。
